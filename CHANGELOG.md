## [0.1.0a1] - 2026-08-08

### Added

- Portable, validated workflow contracts and a ready-queue scheduler.
- Durable SQLite run state, artifact receipts, fenced worktree transfer, and bounded retries.
- Subprocess adapters and configurable profiles for Claude, Codex, Grok, Kimi, and GLM.
- MCP 2.0 task coordination, skill discovery, and a deterministic operator CLI.
- Public-safety, packaging, clean-install, and component verification gates in Woodpecker.
